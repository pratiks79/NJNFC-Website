# NJNFC - New Jersey Nepali Football Club Website

Official website for **NJNFC (New Jersey Nepali Football Club)** — a 501(c)(3) non-profit community soccer organization uniting the Nepali community across New Jersey.

🌐 **Live Site**: [www.njnfc.org](https://www.njnfc.org)

---

## Project Structure

```
Website/
├── index.html          # Home page
├── about.html          # About & Mission
├── leagues.html        # Leagues & Teams / Standings
├── fields.html         # Pickup Fields & Directions
├── gallery.html        # Community Photo Gallery
├── donate.html         # Support & Donate
├── sponsors.html       # Sponsors & Partners
├── contact.html        # Contact & Newsletter
├── css/
│   └── style.css       # Main stylesheet
├── js/
│   ├── data.js         # Club data (rosters, standings, gallery, sponsors)
│   ├── shared.js       # Shared navbar / footer / modals builder
│   └── app.js          # Main app logic & rendering
└── assets/
    ├── icons/
    │   └── njnfc-logo.png   # Official NJNFC crest logo
    └── images/real/         # Authentic club photos
```

## Tech Stack

- **HTML5** — Semantic multi-page structure
- **Vanilla CSS** — Custom design system with dark/light mode
- **Vanilla JavaScript** — Dynamic rendering, modals, gallery filters
- **Lucide Icons** — Lightweight icon set via CDN
- **Google Fonts** — Outfit & Plus Jakarta Sans

## Hosting

Deployed via **GitHub Pages** from the `main` branch root directory.
